# Roadmap

This document communicates areas of product interest, not delivery
commitments. Scope and priority may change.

## Current product foundation

- Desktop task widget.
- Mobile task companion.
- Local-first storage.
- Desktop-hosted local-network synchronization.
- Task scheduling, recurring tasks, tags, and completion history.

## Areas to evaluate

- Stronger sync security, including encrypted transport and safer credential
  lifecycle management.
- Explicit conflict handling for simultaneous or offline edits.
- User-controlled backup and restore.
- More robust data export and import.
- Automated tests for desktop storage, mobile persistence, and sync protocol.
- Release signing and verifiable build artifacts.
- Better platform-specific packaging and release verification.
- Accessibility and usability improvements.

## Principles

- Preserve local-first operation.
- Avoid requiring a hosted account for core task management.
- Keep the desktop and mobile experience consistent.
- Prioritize data integrity, privacy, and predictable behavior.
- Do not advertise a feature as available until it is implemented and
  verified in a published build.

For current shipped functionality, see FEATURES.md and CHANGELOG.md.
