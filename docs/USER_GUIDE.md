# User guide

## 1. Add a task

Open the Today view and use Add Task. Enter a title, then choose the available
priority, time, and tag options before saving. Use the scheduling option to
place a task on today or tomorrow.

## 2. Manage tasks

Select a task to edit its details. Mark it complete when finished. Completed
items are available in the history view; use the available reopen action if
you need to return an item to the active list. Delete tasks you no longer
need.

## 3. Organize with tags and priority

Use the built-in tags or create your own where the interface offers that
option. Priority and time help distinguish what needs attention first.
These are personal organization tools, not calendar or reminder guarantees.

## 4. Recurring tasks

Open the recurring tasks / habits view to add an item that should reappear.
Configure its title and available scheduling options, then enable it. Disable
an item when you no longer want it instantiated. The app performs recurring
task creation during its day-rollover logic; keep the app's data intact.

## 5. Choose a theme

Open the theme palette and select one of the available presets. Theme
preferences are stored locally on each device; they are not necessarily
synchronized between desktop and mobile.

## 6. Connect your phone to your PC

1. Connect both devices to the same trusted Wi-Fi network or a supported
   hotspot configuration.
2. On the PC, open Preferences and find the local IP address and six-digit
   pairing code.
3. On the phone, open Sync.
4. Enter the PC's IP address and the displayed pairing code, then tap
   Connect.
5. Wait for the connected status. The PC should show the connected device.
6. After pairing, the app stores a reconnect credential so you do not need
   to enter a new pairing code for every connection.

The pairing code is single-use and rotates after successful pairing. If you
need to pair another device, use the current code displayed on the PC.

## 7. Disconnect and reconnect

Use Disconnect to end the current session. Use Reconnect to attempt a new
connection with the saved desktop details. If the PC's IP address changes,
update the address in the phone's Sync screen and pair again if necessary.

## 8. Work offline

The phone stores its own data locally. Changes made while disconnected can
be queued and sent when a connection is restored. Keep both devices open and
connected until pending changes have synchronized. Avoid editing the same
item on both devices while offline; the current sync model is snapshot- and
mutation-based, not a full conflict-resolution system.

## 9. Back up your data

Task Thing does not currently provide a hosted cloud backup. Protect your
device and make your own backups of important local data. See
[DATA_STORAGE.md](DATA_STORAGE.md).

## 10. Privacy and safety

Only pair devices on a trusted network. Current sync transport is not
encrypted. Treat pairing codes and reconnect credentials as secrets. See
[PRIVACY.md](../PRIVACY.md) and [SECURITY.md](SECURITY.md).
