# Support and community

Task Thing is an open-source project. Questions, bug reports, feature
requests, and constructive discussion are welcome.

## Before opening an issue

1. Read the [installation guide](docs/INSTALLATION.md).
2. Check the [user guide](docs/USER_GUIDE.md) and [FAQ](docs/FAQ.md).
3. Review the [changelog](CHANGELOG.md) for known changes and fixes.
4. Search existing [GitHub issues](https://github.com/Javanvibecodes/TaskThing/issues).
5. If the problem remains, open a new issue with clear reproduction steps.

## Bug reports

Include your Task Thing version, operating system, device model where
relevant, steps to reproduce, expected behavior, and actual behavior.
Screenshots and logs are useful, but remove task content, personal details,
IP addresses, pairing codes, reconnect tokens, and other secrets first.

For mobile, the app's Report Issue action may prepare a GitHub issue with
diagnostic context. Review the text before submitting it.

## Feature requests

Explain the problem you are trying to solve, your proposed outcome, and
whether it affects desktop, mobile, or both. Feature requests are discussion
starters, not delivery promises.

## Contributing

Code, documentation, design, testing, accessibility, and bug-fix
contributions are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) for the
development workflow and pull-request expectations.

## Security reports

Do not report security vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md) for private disclosure guidance.
